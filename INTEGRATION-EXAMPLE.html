📚 How to Use This on Your Pages

Step 1: Link CSS Files

<link rel="stylesheet" href="css/theme.css">
<link rel="stylesheet" href="css/design-system.css">
<link rel="stylesheet" href="css/responsive.css">

Step 2: Choose a Grid Layout

  • .grid-container - Equal size 2×3 grid
  • .bento-wrapper - Mixed size bento grid
  • .grid-3-col - 3 column grid
  • .grid-4-col - 4 column grid

Step 3: Add Mobile Text Control

  • .desktop-only - Hide on mobile
  • .mobile-only - Show only on mobile
  • .mobile-full - Override auto-reduction
  • .mobile-truncate - Truncate with ...

Step 4: Test Responsiveness

  1. Open DevTools (F12)
  2. Toggle device toolbar (Ctrl+Shift+M)
  3. Test: iPhone SE (375px), iPad (768px), Desktop (1440px)
  4. Verify text reduces to 30% on mobile
  5. Check for horizontal scroll (should be none)

✨ Result:

  • ✅ Desktop: Full content, 2 columns
  • ✅ Mobile: 30% text, 1 column, 70% smaller boxes
  • ✅ Zero horizontal scroll on all devices
  • ✅ Professional appearance everywhere
  • ✅ Fast loading and smooth scrolling
