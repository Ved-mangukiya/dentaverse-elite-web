## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd dentaverse-web
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## 🚀 Deploy to GitHub Pages

1. Push the repository to GitHub
2. Go to **Settings → Pages**
3. Select **Deploy from a branch**
4. Choose your default branch and `/ (root)` folder
5. Your site will be live at `https://yourusername.github.io/dentaverse-web/`

## 📂 File Organization

All files are organized into logical folders:
- **HTML pages** are in `pages/` (except index.html in root)
- **CSS files** are in `css/`
- **JavaScript files** are in `js/`
- **Images** are in `images/`
- **Documents** (PDFs) are in `documents/`

This structure makes the project easy to navigate and maintain.
