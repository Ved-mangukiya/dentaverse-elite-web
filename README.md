## 🏢 About This Project

This is the **official production website** for **Dentaverse**, a UK-based healthcare technology company specializing in Virtual Reality distraction therapy for dental anxiety management. This website serves as our primary digital presence for:

- **Client Acquisition**: Dental practices seeking VR therapy solutions
- **Patient Education**: Information about VR-assisted dental care
- **Business Operations**: Contact, demos, and partnership inquiries
- **Brand Authority**: Clinical research, case studies, and industry insights

**Status**: ✅ Live Production Website  
**Business Type**: B2B Healthcare Technology (SaaS)  
**Target Market**: UK Dental Practices & Clinics

## 🔧 Development Setup

### Prerequisites
- Node.js v14+ (for development server)
- Git (for version control)
- Modern web browser

### Local Development

```bash
# Clone repository
git clone https://github.com/yourusername/dentaverse-web.git
cd dentaverse-web

# Install dependencies
npm install

# Start development server
npm start

# Open browser
# Navigate to http://localhost:3000
```

### File Editing
- **Content Updates**: Edit HTML files directly
- **Styling Changes**: Modify `css/theme.css` or `css/design-system.css`
- **Blog Articles**: Update `js/blog-data.js`
- **Images**: Add to `images/` folder (use lowercase, no spaces)

## 🚀 Deployment

### GitHub Pages (Current)

```bash
# Commit changes
git add .
git commit -m "Update: [description]"

# Push to GitHub
git push origin main

# GitHub Pages auto-deploys
# Live at: https://yourusername.github.io/dentaverse-web/
```

### Custom Domain Setup
1. Add CNAME file with domain: `dentaverse.uk`
2. Configure DNS A records to GitHub Pages IPs
3. Enable HTTPS in GitHub Pages settings
