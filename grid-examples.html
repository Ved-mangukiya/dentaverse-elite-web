📚 How to Control Text on Mobile

✅ Hide Extra Text on Mobile

<div class="grid-box">
  <h3>Feature Title</h3>
  <p>Main description - shows on all devices</p>
  <p class="hide-mobile">Extra details - HIDDEN on mobile!</p>
</div>

✅ Show Different Text for Mobile

<div class="grid-box">
  <h3>Feature Title</h3>
  <p class="hide-mobile">Long detailed description for desktop users with lots of information.</p>
  <p class="show-mobile">Short version for mobile.</p>
</div>

✅ Truncate Long Text

<div class="grid-box">
  <h3>Feature Title</h3>
  <p class="mobile-truncate">This text will be cut off with ... on mobile</p>
</div>

Available Mobile Text Classes:

  • .hide-mobile - Hides element on mobile (<768px)
  • .show-mobile - Shows only on mobile, hidden on desktop
  • .mobile-truncate - Cuts text with ellipsis (...) on mobile
  • .mobile-short - Limits text to ~2 lines on mobile
  • .mobile-compact - Reduces spacing on mobile

Automatic Mobile Optimizations:

  • ✅ Headings automatically smaller on mobile
  • ✅ Paragraphs limited to 2 lines by default
  • ✅ Reduced padding and margins
  • ✅ Smaller font sizes (0.85rem)
  • ✅ Compact spacing between elements

✨ Only essential text shows

📚 How to Use These Grids

1. Equal Size Grid (2×3)

<div class="grid-container">
  <div class="grid-box">Content 1</div>
  <div class="grid-box">Content 2</div>
  <div class="grid-box">Content 3</div>
  <div class="grid-box">Content 4</div>
  <div class="grid-box">Content 5</div>
  <div class="grid-box">Content 6</div>
</div>

2. Bento Grid

<div class="bento-wrapper">
  <div class="left-group">
    <div class="bento-box">Small 1</div>
    <div class="bento-box">Small 2</div>
    <div class="bento-box bento-wide">Wide Box</div>
  </div>
  <div class="right-group">
    <div class="bento-box">Small 1</div>
    <div class="bento-box bento-wide">Wide Box</div>
  </div>
</div>

Available Classes:

  • .grid-container - 2 column equal grid
  • .grid-3-col - 3 column grid
  • .grid-4-col - 4 column grid
  • .grid-auto - Auto-fit responsive grid
  • .bento-wrapper - Bento grid container
  • .bento-wide or .wide - Spans 2 columns
  • .bento-tall or .tall - Spans 2 rows
  • .span-2, .span-3, .span-4 - Column span utilities
  • .card - Card styling with hover effects

Mobile Behavior:

  • ✅ All grids automatically stack to 1 column on mobile (<640px)
  • ✅ Bento grids become single column on mobile (<480px)
  • ✅ Gaps and padding reduce on smaller screens
  • ✅ Span utilities reset to normal on mobile
  • ✅ 100% responsive - no horizontal scroll!
